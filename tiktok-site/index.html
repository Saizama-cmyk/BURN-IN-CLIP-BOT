ClipBot

ClipBot is a personal desktop tool that runs on its owner's own Windows PC. It finds highlight moments in public live streams, edits them into short vertical videos, and posts them to the owner's own social media accounts.

It uses TikTok Login Kit and the Content Posting API only to upload videos to the TikTok account that signed in. It has no other users and no server; nothing is stored anywhere except on the owner's computer.
